# Decision providers

Set `Decision.Provider` to `Ollama` or `Jev`. The environment variable `DECISION_PROVIDER` overrides the setting. Both providers implement the same decision interface, so candidate generation, validation, game execution, audit, and logging are shared.

## Ollama

The active decision provider is the local Ollama chat API:

```text
POST http://127.0.0.1:11434/api/chat
```

The adapter uses model `qwen3:14b` by default. It sends non-streaming chat requests with Ollama's JSON Schema `format` field and `think: true`. Build, tactical-plan, and action requests each receive the current structured game state; action responses are constrained to the legal action IDs generated by the application. Only a schema-valid, currently legal action is executed.

The model endpoint and model name are configurable through `OLLAMA_ENDPOINT` and `OLLAMA_MODEL`; no API key is used. Default local inference timeout is 120 seconds.

`BlindDecisionState.Blind.Key` and `BlindDecisionState.BlindConstraints` are supplied by the local BalatroBot integration. Together they carry the canonical Boss key and all base-game Boss effects without parsing localized text. Generic hard constraints such as a minimum card count, one hand type per round, and one use per hand type per round filter impossible `PlayHand` candidates; all other constraints remain visible to the model for strategy.

The next request receives a bounded `JevRunMemory` of the last 12 decision records from the current run. The selected action and Ollama's complete response (including any separate thinking field) are stored in the decision log for later audit.

Source: [Ollama chat API](https://docs.ollama.com/api/chat).

## Jev

Jev uses TypeSafe's System One endpoint:

```text
POST https://api.typesafe.ai/v1/systemone
Authorization: Bearer <JEV_API_KEY>
```

It uses the configured `Jev.Endpoint`, `Jev.Model`, and `Jev.TimeoutSeconds`. The API key is read from `JEV_API_KEY` first, then from `Jev.ApiKey` in the ignored `appsettings.local.json`. The adapter sends structured game state and closed choice criteria; it accepts only a returned action ID that exists in the supplied candidate list.
